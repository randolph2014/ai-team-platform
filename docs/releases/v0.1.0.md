# AI Team Platform v0.1.0 Release Notes Draft

> Draft status: this document prepares the first public release notes. It is not a published GitHub Release until a maintainer creates tag `v0.1.0` and publishes it.

## Summary

AI Team Platform v0.1.0 is the first public pre-1.0 release candidate for an AI-assisted software delivery platform. It packages the workflow engine, CLI, API, dashboard, worktree isolation, context scanning, quality gates, persistence, and Harness governance assets into one repository-owned platform.

## Highlights

- Workflow engine for agent-based delivery pipelines.
- CLI entrypoint through `ai-team run`, `ai-team status`, `ai-team serve`, `ai-team cleanup`, and `ai-team install-skill`.
- FastAPI REST and WebSocket service for run state and dashboard integration.
- React, TypeScript, Tailwind, and Vite dashboard for operational visibility.
- Per-run Git worktree isolation.
- Context Scanner support for project instruction files.
- Quality gates and report artifacts for delivery verification.
- PostgreSQL persistence, Redis/RQ worker support, and Docker Compose setup.
- Harness Governance Layer for project rules, skills, checks, baselines, and task memory.
- OSS maintainer documentation with contributing and security reporting guidance.
- MIT license.

## Validation Before Publishing

Run the checks that match the release scope:

```bash
./.venv/bin/python -m pytest
cd web && npm run test
cd web && npm run build
bash scripts/check_repo_hygiene.sh
```

For full-stack release confidence, run the real-stack smoke when Docker is available:

```bash
cd web && npm run smoke:real-stack
```

- The project is pre-1.0 and public API boundaries may still evolve.
- Public adoption signals are early: release, issue triage, and PR review workflows are being established.
