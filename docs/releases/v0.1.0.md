# AI Team Platform v0.1.0 Release Notes

Published: 2026-05-31

## Summary

AI Team Platform v0.1.0 is the first public pre-1.0 release for an AI-assisted software delivery platform. It packages the workflow engine, CLI, API, dashboard, worktree isolation, context scanning, quality gates, persistence, and Harness governance assets into one repository-owned platform.

## Highlights

- Workflow engine for agent-based delivery pipelines.
- CLI entrypoint through `ai-team run`, `ai-team status`, `ai-team serve`, `ai-team cleanup`, and `ai-team install-skill`.
- FastAPI REST and WebSocket service for run state and dashboard integration.
- React, TypeScript, Tailwind, and Vite dashboard for operational visibility.
- Per-run Git worktree isolation.
- Context Scanner support for project instruction files.
- Quality gates and report artifacts for delivery verification.
- PostgreSQL persistence, Redis/RQ worker support, and Docker Compose setup.
- Harness Governance Layer for project rules, skills, checks, baselines, and task memory.
- OSS maintainer documentation with roadmap, changelog, contributing, security reporting, issue templates, and PR template.
- MIT license.
- README minimal local confirmation path that does not require PostgreSQL, Redis, Docker, or Playwright.
